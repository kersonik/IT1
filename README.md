# IT1 - Školní projekty (1. ročník)

Kolekce projektů a cvičení z 1. ročníku střední školy pro předměty Programování (PRP) a Programové vybavení (PVY).

## Struktura repozitáře

### PRP (Programování)
- **[pingpong](./PRP/pingpong/)**: Stolní tenis v Pythonu vytvořený s využitím knihovny Pygame. Obsahuje detekci kolizí, počítání skóre a plynulé ovládání hráčů.

### PVY (Programové vybavení & Web)
- **[seznamy-tabulky](./PVY/seznamy-tabulky/)**: Procvičování sémantického HTML5 a kaskádových stylů (CSS3) pro tabulky a strukturované seznamy.
- **[pololetni-projekt](./PVY/pololetni-projekt/)**: Vícestránková statická webová prezentace zaměřená na hardware, software a historii výpočetní techniky.
- **[rocnikovy-projekt](./PVY/rocnikovy-projekt/)**: Ročníkový projekt webových stránek postavený na redakčním systému WordPress s vlastní konfigurací a pluginy.
